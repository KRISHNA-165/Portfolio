Supabase over custom auth

Engineering Decisions
QR codes over manual check-in

Manual entry at events caused 3–5 second delays per attendee. QR scan + server validation reduced check-in time to under 800ms and eliminated human entry errors.

Rate limiting at middleware level

Brute-force attacks on the registration endpoint were caught in testing. Express-rate-limit at the route level blocked 50+ req/min per IP without touching business logic.

Modular REST architecture over monolith

Separating auth, events, and attendance into independent routers made it possible to test and deploy each domain independently, cutting debugging time significantly.

Engineering Decisions
SQLite (local-first) over cloud DB

Finance data is sensitive and users need offline access. Expo SQLite + AsyncStorage gave zero-latency reads, full offline capability, and no backend cost — the right tradeoff for a personal finance app.

Zustand over Redux

React Native with Expo doesn't need Redux's ceremony for local app state. Zustand's 1KB footprint and direct store mutations cut state management code by ~60% compared to an equivalent RTK setup.

Expo Router over React Navigation

File-system routing mirrors Next.js conventions, making navigation logic readable and reducing configuration boilerplate. Deep linking worked out of the box without manual linking setup.
